Zero to Robot
=============

Start with :doc:`../yearly-overview/2027-overview` for the confirmed
control-system changes. Then assemble your robot and plan the wiring for
the hardware you have.

For software installation, imaging, radio setup, and programming, use
`WPILib's 2027 Zero to Robot guide
<https://docs.wpilib.org/en/latest/docs/zero-to-robot/introduction.html>`_.

The wiring guides below include older roboRIO examples. Check the hardware
scope at the top of each guide before using its diagrams.
