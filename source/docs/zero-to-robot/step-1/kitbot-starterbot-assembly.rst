Kitbot Assembly
===============

Use the official instructions for the Kitbot and drive base you have.

Official resources
------------------

* `FIRST Kitbot resources
  <https://www.firstinspires.org/resources/library/frc/kitbot>`_: build
  instructions, drawings, CAD, and supporting material.
* `FIRST Kit of Parts
  <https://www.firstinspires.org/resources/library/frc/kit-of-parts>`_:
  drive-base and kit resources.

As of October 14, 2026, the Kitbot page lists the 2026 build resources.
Check the season shown on the instructions before using them for a 2027
robot. Use the 2027 resources when FIRST publishes them.

Before wiring
-------------

* Check the assembled frame, drivetrain, and fasteners against the instructions.
* Plan access to the battery, main breaker, controller, and radio.
* Leave space for wiring, strain relief, and component replacement.

For the control-system changes, see
:doc:`/docs/yearly-overview/2027-overview`. Then use the wiring instructions
for the components installed on your robot.
